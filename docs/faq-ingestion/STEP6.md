Выполнен локально 07–08.11.2026. Код: `c3bd2c0` в `faq-ingestion-plan`.
Production не менялся. Сводка доказательств: [interface-verification.json](interface-verification.json).

## Результат

Каждая новая серверная цитата сохраняет `url`, `document_type`,
`source_format`, `source_url_status`; для FAQ — номер, вопрос и тематический
путь. Они записываются вместе с прежними адресом `source_id/snapshot_id/block_id`,
номером, оригинальной выдержкой и диапазоном. URL строится из того же
снимка: HTML-страница и якорь её заголовка либо официальный PDF и физическая
страница. Каталог FAQ не подменяет тематическую страницу.

Карточки существующего Streamlit-интерфейса используют `st.link_button`.
Тип материала, номер вопроса, тема, PDF-страница, версия и выдержка остаются
видимы; подписи поддерживают en/pt/uk/ru. Старая история без URL читается
без реконструкции ссылки из нынешнего корпуса. Повторное получение и
дочитывание возвращают прежний номер только для той же записи цитаты.

Живые ссылки не объявляются архивами. Официальный PDF CIRS проверен отдельно:

| Файл | SHA-256 |
| --- | --- |
| Сохранённый CIRS | `e8671caafbcda885e5c87d451d8d2ef121b36bc7ab63eb2eb1ab474970b15a72` |
| Официальный PDF при проверке | `eb69f3fee3f088a943b37cb6f428e2a75b39b0de590e05c352aad390e1249a33` |

Это разные файлы. Реестр и цитаты сохраняют честный статус `candidate`,
карточка предупреждает о возможной другой редакции. Ни PDF-снимок,
ни его идентичность, ни прежний CIRS в корпусе не заменялись.

## Исправления, необходимые для приёмки

Два варианта инструкций модели оставляли перестановку числовых цитат:
утверждение о CIRS могло получить номер FAQ. Применён Attack the Premise:
предпосылка — модель и сервер совместно владеют соответствием номера
выдержке; акторов два. Назначение нумеровать снято с модели.

Сервер выдаёт описательный `citation_key` с типом, подписью и исходным ID.
Модель копирует полный ключ в квадратных скобках. Сервер проверяет ключ
по реестру и отображает исходный `[N]`; неизвестный, обрезанный ключ и попытка
самостоятельной числовой нумерации отклоняются. Ключи, разделённые между
токенами потока, буферизуются; поток, сохранённый ответ и AI-сообщение в
PostgresSaver содержат одинаковые нормализованные ссылки. Старые числовые
цитаты истории сохраняются. Общие лимиты и правила доступа не менялись.

Проверка содержания также нашла польский ответ на украинский сценарий.
Короткие языковые коды заменены полными названиями из одного справочника,
общего для UI и агента. Итоговые украинские ответы проверены как украинские.

Сохранено различие закона и административного разъяснения. Релевантные
смешанные ответы цитируют оба типа; квоты источников или обязательной
FAQ-цитаты для любого вопроса нет.

Для Mutator использованы изолированный ARM64 parser cache, абсолютный
интерпретатор проекта и один worker для тестовой БД. `--no-coverage`
применён к выполнению мутаций, поскольку coverage.py не выдаёт отдельные
line hits для физических строк внутри некоторых покрытых SQL-выражений
и f-строк. Это не пропуск проверки: SQL-мутации выполнены и уничтожены.
Выжившие мутации различения PDF/HTML-подсказок и задержки обычного текста
в потоке закрыты поведенческими проверками.

Начальный поиск каждого живого ответа выполнялся RagTools с неизменённым
эталонным запросом. Настоящие embeddings и ранги Шага 5 переиспользованы из
API-аудита; последующие инструменты и итоговый ответ работали с реальной
моделью. Это приёмка ответа и интерфейса; автономная переформулировка
начального запроса здесь отдельно не измерялась. Поиск не менялся,
результаты FAQ 48/48 и прежнего CIRS 36/36 относятся к Шагу 5.

В промежуточном keyed-прогоне два дополнительных поиска русского сценария
частичного резидентства получили повторяющиеся IDs от reranker. Существующая
валидация отклонила оба ответа; ранги не исправлялись и не подменялись.
Итоговый прогон после полного названия языка прошёл все 16 сценариев.
Отвергнутые ответы и API-аудиты сохранены, без заявления о безошибочности API.

## Артефакты и usage

Полные материалы вне Git: `data/faq-step6-live/`. Принятый набор:
`accepted/summary.json`, `accepted/mixed-*.json`, API receipts и
`accepted/ui-verification.json`. Проверка ссылок — `links-verification.json`,
скачанный PDF и пять HTML-страниц. Скрипты проверки включены в этот каталог;
их хеши сохранены в [interface-verification.json](interface-verification.json).

Принятый чат: **32 настоящих Responses-ответа**, 242850 input / 9993 output
tokens. Все чат-попытки, включая отвергнутые: 130 ответов,
910332 input / 36717 output tokens. Дополнительные настоящие embedding/reranking
ответы хранятся отдельно и перечислены в JSON-сводке. Повторное чтение
старых API-ответов не считается новой платной обработкой. Денежная оценка
без проверки тарифа не приводится.

Результат зафиксирован локально. Прежнее ограничение на перенос/push в
`master` сохранено; неиспользуемых worktree нет, необходимые доказательства
и пользовательские процессы не удалялись.
