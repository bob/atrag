# Векторный поиск в MVP — 01.11.2026

По решению пользователя FTS и hybrid исключены из реализации MVP.
Смысловые вопросы на ru/en/pt используют только точный cosine search pgvector;
статьи и пункты выбираются SQL-фильтрами без API-вызова.
Возможное возвращение FTS описано в [будущих расширениях](README.md#10-будущие-расширения).

## Изменение контракта

- Удалены выбор режима, `RetrievalMode`, параметры `mode`/`rrf_k`, CLI `--mode`,
  настройка `ATRAG_RRF_K`, RRF и `text_rank`.
- Смысловой `score` равен `1 - cosine_distance`; `vector_rank` показывает место
  среди 50 кандидатов. Равные расстояния упорядочиваются по `fragment_id`.
  Точные адреса имеют `score=1.0`, `vector_rank=null` и исходный порядок частей.
- `evaluate` запускает 36 поисковых случаев один раз и 18 расширений отдельно.
  Новый отчёт имеет `schema_version=2`, сохраняет метку алгоритма `vector` и
  прежние группы языков. Полный живой эталон требует 18 embeddings запросов.
- Миграция `0003_vector_search` удаляет GIN-индекс и вычисляемую колонку
  `search_vector`. Исходные тексты, payload, связи и оплаченные векторы сохраняются.
  Историческая миграция 0002 и её обратимое восстановление остаются только
  для совместимости миграций; приложение не использует лексический поиск.
- Формат переносимого пакета не изменён. Для существующей БД нужен обычный
  `uv run atrag db migrate`; повторная векторизация корпуса не нужна.

## Проверки изменения

До изменения воспроизведены пять ожидаемых падений: старые режимы CLI,
тройная оценка случая, прежнее ранжирование и сохранённая FTS-колонка.
Проверены новая косинусная оценка, порядок результатов, точные адреса без API,
миграция существующего корпуса, откат к 0002 и повторное обновление без изменения
идентификаторов, payload и векторов.

Полный прогон: **480 тестов**, **100% покрытия 2741 строки** приложения.
Все **50/50 мутаций** затронутых модулей уничтожены; в новой миграции нет
применимых мутаций инструмента, её upgrade/downgrade проверены PostgreSQL-тестом.
CRAP максимум 9; дублирования от 0.8 нет. Ruff check/format, синтаксис
Python 3.13 и `git diff --check` проходят. Runtime остаётся Python 3.14,
Ruff — `py313`. База `atrag_test_context_20261101` сохранена, таблицы очищены.
