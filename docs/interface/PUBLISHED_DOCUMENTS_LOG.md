# Даты ingestion опубликованных документов — 2026-11-08

## Действия и причины

1. Прочитаны инструкции проекта, `ub-mode` и рекомендации Streamlit по тексту и тестированию. Проверены чистый Git и worktree: существует только активный, удалять нечего.
2. Найдены вывод хешей в `corpus_view` и сохранённый `source_snapshots.ingested_at`. Для интерфейса нужна дата именно опубликованной версии, а не последней подготовленной версии или дата публикации корпуса.
3. Добавляется интеграционная проверка пользовательского вывода на PostgreSQL: пустой список, два документа с разными датами, замена версии и удаление документа. До правки реализации проверяется отсутствие требуемых дат.
4. Подтверждена красная фаза на четырёх языках: старый интерфейс выводит хеш даже для пустого корпуса. Первый запуск заблокирован песочницей; повторный разрешённый запуск использует существующую тестовую БД без её пересоздания.
5. Ресурс интерфейса теперь одним запросом получает имя и `ingested_at` опубликованной версии. Убраны вывод состава корпуса, версии и неиспользуемые переводы. Дата показывается под каждым именем в UTC с точностью до минуты; обновлены существующие UI fixtures.
6. Пройдено 69 проверок UI, ресурсов, публикации и PostgreSQL. Использована существующая `atrag_test_context_20261101`, таблицы очищаются штатными fixtures. Добавлена проверка UTC при переходе даты; проверены четыре языка, два разных документа, неопубликованная версия, замена и удаление.
7. Ruff, форматирование, `ty` и разбор AST в режиме Python 3.13 прошли; runtime Python 3.14 и Ruff `target-version = "py313"` сохранены.
8. Выполнены Crapper (изменённые функции: CRAP 1 и 3, максимум в проверенных файлах 7), Dryer (дублирования от 0.8 нет) и Mutator. Все три мутации изменённых функций уничтожены. Две строки JOIN проверены отдельно без фильтра coverage: Python относит выполнение цепочки к другой строке. Использован существующий локальный ARM-кеш парсеров.
9. Установленный Streamlit 1.66.1 не поддерживает agent API, а браузерный host недоступен. Через нативный Safari открыт временный localhost-предпросмотр реальной точки входа с отсоединёнными тестовыми данными. В раскрытом блоке видны только имена и даты, хешей и строк версии нет. Консоль без ошибок; временный сервер остановлен. Внешних записей и запросов к моделям не выполнялось.
10. Проверен diff и состав отправки: `origin/master` остаётся на `4df40c0`, текущая ветка содержит 18 предшествующих локальных коммитов. Правка сохраняется отдельным коммитом; отправка всей накопленной ветки в master требует решения пользователя.
