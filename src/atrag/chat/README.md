# Chat

Контракты находятся в `atrag.schemas.chat`: `identity` описывает доверенные
OIDC claims, `conversations` — значения пользователя, диалога и хода,
`tools` — аргументы RAG-инструментов.

| Пакет | Назначение |
| --- | --- |
| `api` | Адаптер LangChain: `atrag.chat.api.tools.RagTools` |
| `services` | Сценарии `ChatService` и `RagService`, валидация входа и управление извлечением |
| `core` | Чистые операции допуска, регистрации цитат и учёта usage |
| `db` | SQL, проверки владельца, блокировка хода и сохранение данных |
| `client` | Место для собственных внешних клиентов чата; пока содержит только пакет |

`api` вызывает `services`; сервисы используют `core` и `db`. Схемы не зависят
от реализации чата. Создание embedding-клиента и повторные запросы остаются
общими для ingestion/retrieval и не дублируются в chat.

Пользователь (`User`) определяется issuer/subject, а email разрешает вход.
Диалог (`Conversation`) принадлежит пользователю. Ход (`Turn`) сохраняет
вопрос, язык, состав корпуса, историю и бюджет извлечения. Цитата связывает
номер в ответе с исходным срезом документа.

Записи пользователя и диалога выполняются одной транзакцией в `ChatStore`.
`RagService` держит блокировку строки хода до сохранения цитат и расхода
бюджета; параллельные инструменты используют общее сохранённое состояние.
